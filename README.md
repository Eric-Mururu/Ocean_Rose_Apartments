# Ocean Rose Apartments

A responsive accommodation website for an apartment business in Watamu, Kilifi County, Kenya. I designed and built it from scratch as part of my web development training.

**Live website:** https://eric-mururu.github.io/Ocean_Rose_Apartments/

## Features

- Responsive layout that works on phones, tablets and computers
- Navigation bar linking to Home, Apartments, Amenities, Location, Book Now and Contact
- Apartment cards for Studio, One-Bedroom and Family apartments
- Amenities section (swimming pool, free Wi-Fi, equipped kitchen, beach access, secure parking)
- Embedded location map for Watamu
- Booking enquiry form with name, email, phone, apartment type, dates, number of guests and special requests
- Contact section

## Built with

- HTML5
- CSS3
- Bootstrap
- Git and GitHub
- GitHub Pages for hosting

## What I learned

- Structuring a multi-section page with semantic HTML
- Building responsive layouts with Bootstrap and custom CSS
- Designing a booking form for a small business
- Managing a project with Git and publishing it with GitHub Pages
